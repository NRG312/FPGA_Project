# FPGA Digital Logic and CPU Projects

A collection of FPGA projects exploring digital logic design, arithmetic circuits, decoders, and custom processor architecture.

The repository documents my progress from basic digital circuits to building a custom microprocessor and experimenting with VGA output.

## Project Overview

The projects are organized into two main development branches, representing different stages of learning and experimentation with FPGA design.

### 1. Basic Digital Logic and Microprocessor

This branch contains smaller digital logic projects developed to understand the fundamentals of hardware design.

Projects include:

- **Binary calculators** — simple arithmetic circuits, including 1-bit and 4-bit designs.
- **Decoders** — digital logic circuits for decoding input signals.
- **Arithmetic circuits** — building blocks for performing basic calculations.
- **Microprocessor experiments** — combining digital logic components into a simple processor for arithmetic operations.

These projects provided a foundation for understanding how individual logic circuits can be combined into more complex digital systems.

### 2. CPU + VGA

This branch contains a more advanced experiment combining a custom CPU with VGA output.

The main goal was to develop a small processor and integrate it with a video output system.

Implemented functionality includes:

- A custom CPU architecture.
- Basic arithmetic operations: addition and subtraction.
- VGA output integration.

The processor is a work in progress, with its current instruction and arithmetic capabilities limited to the functionality implemented so far.

## Technologies and Hardware

- FPGA development
- Digital logic design
- Hardware description language (HDL)
- Tang Nano FPGA development board

## Learning Goals

- Understand digital logic and arithmetic circuits.
- Explore how decoders and logic components work together.
- Design a simple processor from the ground up.
- Learn how a CPU executes basic arithmetic operations.
- Experiment with integrating a processor and VGA output on an FPGA.

# Projekty z zakresu logiki cyfrowej i procesorów na układach FPGA

Zbiór projektów realizowanych na układach FPGA, obejmujących zagadnienia projektowania logiki cyfrowej, układów arytmetycznych, dekoderów oraz architektury własnych procesorów.

Repozytorium dokumentuje mój rozwój: od prostych układów cyfrowych, przez budowę własnego mikroprocesora, aż po eksperymenty z generowaniem sygnału wideo VGA.

## Przegląd projektów

Projekty podzielono na dwie główne ścieżki rozwojowe, odzwierciedlające różne etapy nauki i eksperymentowania z projektowaniem układów FPGA.

### 1. Podstawy logiki cyfrowej i mikroprocesory

Ta ścieżka zawiera mniejsze projekty z zakresu logiki cyfrowej, stworzone w celu zrozumienia fundamentów projektowania sprzętowego.

W skład projektów wchodzą:

- **Kalkulatory binarne** — proste układy arytmetyczne, w tym wersje 1-bitowe i 4-bitowe.
- **Dekodery** — układy logiki cyfrowej służące do dekodowania sygnałów wejściowych.
- **Układy arytmetyczne** — moduły służące do wykonywania podstawowych obliczeń.
- **Eksperymenty z mikroprocesorami** — łączenie komponentów logiki cyfrowej w prosty procesor zdolny do wykonywania operacji arytmetycznych.

Projekty te pozwoliły zrozumieć, w jaki sposób poszczególne układy logiczne można łączyć w bardziej złożone systemy cyfrowe.

### 2. Procesor (CPU) i interfejs VGA

Ta ścieżka obejmuje bardziej zaawansowany projekt, łączący autorską architekturę procesora z obsługą wyjścia wideo VGA.

Głównym celem było zaprojektowanie niewielkiego procesora i zintegrowanie go z systemem wyświetlania obrazu.

Zaimplementowane funkcjonalności obejmują:

- Autorską architekturę procesora.
- Podstawowe operacje arytmetyczne: dodawanie i odejmowanie.
- Integrację z wyjściem VGA.

Procesor jest wciąż rozwijany; jego obecny zestaw instrukcji oraz możliwości arytmetyczne ograniczają się do funkcji zaimplementowanych na tym etapie prac.

## Technologie i sprzęt

- Projektowanie układów FPGA
- Projektowanie logiki cyfrowej
- Języki opisu sprzętu (HDL)
- Płytka rozwojowa FPGA: Tang Nano

## Cele edukacyjne

- Zrozumienie logiki cyfrowej i układów arytmetycznych.
- Poznanie zasad współpracy dekoderów oraz innych komponentów logicznych.
- Zaprojektowanie prostego procesora od podstaw.
- Zrozumienie sposobu, w jaki procesor wykonuje podstawowe operacje arytmetyczne.
- Eksperymentowanie z integracją procesora i wyjścia VGA w układzie FPGA.
